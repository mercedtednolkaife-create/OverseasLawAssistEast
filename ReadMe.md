### 一、 系统定位与核心价值

在中国基建央企、国企“走出去”参与“一带一路”及东盟互联互通工程的实务中，出海企业与法务团队常面临多重严峻挑战：东道国强行法与本地化行政规章庞杂、语言壁垒森严、合同背靠背陷阱频现、见索即付保函恶意索兑风险高发；同时，通用大模型存在严重的“法条幻觉”、生硬的“AI 模板味”以及脱离工程实操的“单一伪量化胜诉率（如机械展示 88% 胜诉率）”。

**OverseasLawAssist（域外法查明与深度研判智能工作台）** 是专为中国涉外法官、涉外仲裁员、基建央国企涉外法务合规官及跨境争议解决律师研发的现代化桌面级专业平台。系统已彻底剥离宽泛的历史欧美商事法域，全面聚焦于**东盟 6 国（印度尼西亚、越南、马来西亚、新加坡、泰国、菲律宾）建设工程（EPC/PPP/特许经营/跨境并购/联营体）法律风险防范、合同强行法红线扫描、履约争议推演、全周期合规自测、涉外多边投资争端（ISDS）应对与 Local Counsel 专家协同**。

系统严格贯彻**司法中立防线（V8 Anti-Predictive Guardrail）**，彻底摈弃伪量化胜诉率，创新采用**假定条件推演矩阵（Condition Precedent If-Then Matrix）**与**三维定性结论遥测**，依托确定性算子、三层刚性安全哨兵、双层双 FAISS 1024 维 BGE-M3 向量引擎与真实 SQLite 持久化，为出海基建提供端到端真实闭环的决策支持。

### 四、 核心功能与工作台详述

#### 1. 首屏极速双轨制 (`HomeLandingView.tsx`)
* **轨道 A（占宽 60% · 30 秒合同强行法红线极速扫描）**：
  * 支持输入英文或中英双语合同条款，提供印尼 SEMA 3/2023、大马 CIPAA 35、新加坡保函止付等典型高危条款一键填入；
  * 点击即刻输出三联式诊断卡：**① 强行法效力判定**（如：违反 CIPAA 第 35 条 · 法定绝对无效） $\to$ **② 诉讼/仲裁后果预警** $\to$ **③ 平衡修改示范条款（Redline 一键复制）**；
  * 底部提供 **【以此条款一键升级为深度专案】**，自动携带参数打开建案弹窗。
* **轨道 B（占宽 40% · 深度专案查明与标杆示范卷）**：
  * 顶部常驻 **【+ 粘贴邮件/索赔函极速建案】** 入口；
  * 下方展示 C101（印尼火电 TKDN 与工期）、C102（越南海风并购准入）、C103（大马分包背靠背）、C104（新加坡地铁保函止付）标杆案卷卡片，点击秒切进入研判舱。

#### 2. 零门槛智能案情抽提舱 (`CaseEntryModal.tsx`)
* **AI 智能要素抽提舱 (Smart Ingestion Box)**：
  * 粘贴一段原始英文往来邮件、业主索赔通知函（Claim Notice）或招标文件，点击 **【一键智能抽提建案要素】**；
  * 调用后端 `POST /api/cases/extract-intake`，2 秒内自动提炼项目名称、东道国、准据法、生命周期阶段（`pre_investment` / `execution_dispute`）、工程业态、事实与诉求摘要，并精准抽取天数、TKDN 比例等工程数值参数填入表单；
* **跨组件带参预填孵化**：
  * 从【合规中心未达标项】、【六国比选矩阵】或【合同红线扫描仪】跳转时，自动预填上下文并高亮来源。

#### 3. 专案深度研判舱——生命周期双模自适应「四切面」矩阵 (`CaseAnalysisView.tsx`)
支持键盘快捷键 `1`、`2`、`3`、`4` 秒切，视图随生命周期模式（投前准入 `pre_investment` vs 履约争议 `execution_dispute`）自动切换专业话术与评估维度：

* **切面 1：决策全景看板 (Executive Verdict & If-Then Matrix)**
  * **三维定性结论遥测带**：严守 V8 防线，废除虚假单一胜诉率。争议模式展示：`[实体法理支持度：强支持 (82%-90%)]`、`[程序抗辩敞口：可控中度威胁]`、`[反制阻断预期：高确定性阻断]`；投前模式展示外资准入可行性、属地强行法敞口与国资委 35 号令备案就绪度；
  * **假定条件推演矩阵 (If-Then Condition Matrix)**：三阶泳道（乐观假定 / 基准稳健 / 底线突破），清晰揭示自由心证分水岭；
  * **准据法脱钩穿透警示卡**：当东道国与合同准据法不一致时，自动呈现琥珀色 `Lex Loci Override` 穿透警示。
* **切面 2：争点拆解 & 要件四态涵摄 (Issues & Statutory Elements)**
  * 左栏争议焦点/准入支柱列表，右栏对应要件四态胶囊比对卡（`✓ 已满足`、`◐ 部分满足`、`✕ 缺失`、`? 存疑`）；
  * 每张卡片分为：`[法定要件与法条徽章]` $\to$ `[在卷事实涵摄判定]` $\to$ `[证据缺口与补强入口]`；点击法条直接呼出右侧副驾坞精读。
* **切面 3：工程沙盘 & 攻防工坊 (What-If Sandbox & Battlecards)**
  * **左舱精密沙盘**：在滑轨上物理绘制法定红线刻度锚点（`28d FIDIC 失权线`、`40% TKDN 红线`、`30d 中信保报损线`）；
  * **右舱实时联动**：滑块越过红线瞬间触发高亮呼吸动效，实时联动刷新后端返回的 **《中英双语商务谈判反驳话术卡》** 与 **《7 日内紧急发函与取证清单》**；内置竞态版本锁，保证快速拖拽丝滑不跳字。
* **切面 4：法源穿透图谱 & 意见书交付 (Citation Graph & Quality Gate)**
  * 顶部展示 Critic V1~V12 司法门禁遥测条；
  * 左下展示 3-Layer 交互式法源拓扑图谱（`InteractiveCitationGraph.tsx`）；
  * 右下提供实时公文级双语意见书预览器，支持一键导出最高法标准 Word (.docx) 报告与合规手册。

#### 4. 轻量独立工具箱与双层法典检索库 (`Toolbox & Dual-Layer Search`)
* **合同红线 & 外律意见书核验仪 (`MaterialVerificationView.tsx`)**：
  * 支持涉外合同条款强行法扫描与外律意见书引证防伪验真；
  * 新增 **`[+ 挂载体检记录至当前案卷]`**（调用 `POST /api/cases/{id}/attach-artifact` 真实存入案卷运行库）与 **`[以此条款新建深度专案]`**。
* **东盟六国现行法典与判例双层搜索引擎 (`NormSearchEngineView.tsx`)**：
  * **双层检索调度模式**：支持 `AUTO`（智能分级级联：优先命中 L1 核心强行法；若语义外溢或命中度不足则自动级联扩散 L2 参考层）、`L1_ONLY`（仅检索核心强行法库）、`L2_ONLY`（仅检索参考条约/FIDIC库）、`DUAL_MERGE`（双层动态融合）；
  * **L2 轻量级 GraphRAG 1-Hop 拓扑扩散**：当命中 L2 参考规范（如 FIDIC 条款或 ACIA 投资保护）时，自动基于 `reference_edges` 拓扑网络扩散召回关联的仲裁先例、附属条款与上位条约；
  * **权威认证分层徽章**：检索结果卡片实时显示翡翠绿 **【L1 核心强行法】** 或琥珀金 **【L2 广覆盖参考】** 权威等级，直观指示法条强行法层级；支持一键 **`[+ 引用至当前案卷]`**。
* **东盟 Local Counsel 与 DAAB 专家协同枢纽 (`ExpertConsultsView.tsx`)**：
  * 预置 6 国资深大律师与仲裁员档案，在线执行利益冲突 (COI) 排查，排查会商记录一键挂载至案卷。

#### 5. 东盟合规与排雷知识底座 (`ComplianceCenterView.tsx`)
* **五阶段 × 三道防线合规体检表**：

  * 发现瑕疵或未达标项时，右侧浮现 **`[针对此缺口发起专案推演 ➔]`**，携带全部上下文参数一键建案。

#### 7. 全局聚焦命令舱 (`CommandPaletteModal.tsx`)

### 六、 系统部署与操作指引

#### 1. 运行环境要求
* **操作系统**：Windows 10/11 (x64) 或 Linux (Ubuntu 20.04+)
* **Python 环境**：Python 3.10.x
* **Node.js 环境**：Node.js v18.0+ / npm 9.0+
* **GPU 算力（可选）**：NVIDIA GPU（支持 CUDA 加速，用于本地 BGE-M3 向量化；无 GPU 自动平滑回退至 CPU）

#### 2. 服务端与前端启动步骤

**步骤一：启动 Python FastAPI 后端服务**
```powershell
# 1. 激活虚拟环境（若有）
.\v\Scripts\Activate.ps1

# 2. 设置 DashScope API Key（可选，无 Key 时本地确定性规则引擎 100% 自动兜底）
$env:OPENAI_API_KEY="your-api-key-here"

# 3. 启动 FastAPI 核心后端服务
uvicorn lawagent.api.main:app --host 127.0.0.1 --port 8000 --reload
```
- 后端 Swagger 接口文档：`http://127.0.0.1:8000/docs`
- 健康探针接口：`http://127.0.0.1:8000/api/health`

**步骤二：启动前端交互控制台**
另起一个终端窗口：
```powershell
cd FrontEnd
npm install      # 初次运行安装依赖
npm run dev
```
- 前端访问地址：`http://localhost:3000`
- 请求通过 Vite 代理自动转发至 `http://127.0.0.1:8000/api`。

**步骤三：自动化回归测试与生产构建校验**
```powershell
# 1. 运行后端全量 21 项单元与端到端集成测试（涵盖 L1/L2 双层检索、轻量 GraphRAG 拓扑、沙盘算子与前置门禁）
$env:PYTHONPATH="."
python -m pytest tests/ -v

# 2. 运行 Phase 6 双层知识库与多边条约 22 项全量语义问句验证
python scripts/verify_phase6_full_upgrade.py

# 3. 运行前端生产编译构建检查（0 Error, 0 Warning, 耗时约 283ms）
npm --prefix FrontEnd run build
```
