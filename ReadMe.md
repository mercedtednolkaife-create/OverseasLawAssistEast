# 域外法查明与深度研判智能工作台 (OverseasLawAssist)
## 面向东盟基建工程与出海央国企合规转型 · 用户手册与技术全景指南

---

### 一、 系统定位与核心价值

在中国基建央企、国企“走出去”参与“一带一路”及东盟互联互通工程的实务中，出海企业与法律法务团队常面临多重严峻挑战：东道国法律条文与本地化行政规章庞杂、语言壁垒森严、合同背靠背陷阱频现、见索即付保函恶意索兑风险高发，且通用大语言模型缺乏工程法律实务积淀，存在法条幻觉与论证脱节。

**OverseasLawAssist（域外法查明与深度研判智能工作台）** 是专为中国涉外法官、涉外仲裁员、基建央国企法务合规官及跨境争议解决律师研发的专业级法律科技平台。系统已彻底剥离宽泛的历史欧美商事法域，全面聚焦于**东盟 6 国（印度尼西亚、越南、马来西亚、新加坡、泰国、菲律宾）建设工程（EPC/PPP/特许经营/M&A/联营体）法律风险防范、强行法红线扫描、履约争议推演、全周期合规自测与 Local Counsel 专家协同**。

系统依托 **LangGraph 确定性状态图流转**、**多 Agent 协同博弈**、**双通道 Agentic RAG**、**FIDIC 多版本跨版本降级检索**、**准据法脱钩穿透审查** 与 **国家安全经济安全哨兵**，严格贯彻**司法中立防线（V8 Anti-Predictive Guardrail）**，彻底摈弃伪量化胜诉率，创新采用**假定条件推演矩阵（Condition Precedent If-Then Matrix）**，为出海基建提供端到端严谨闭环决策支持。

### 二、 支持法域与权威数据底座 (Pure ASEAN & FIDIC Architecture)

#### 1. 东盟 6 国 2026 现行有效法源与司法部“法通网”三语对齐
* **印度尼西亚 (`asean_id`)**：印尼最高法院《2023年第3号通告》(SEMA No. 3/2023，反制纯英文合同机械无效抗辩)、《建筑服务法》(UU No. 2/2017) 第 57 条、能矿部 `MEMR Reg 11/2024` 与工业部电力设备本地化率 (TKDN) 强行法、印尼《民法典》(KUHPerdata) 第 1338 条善意履约原则；
* **越南 (`asean_vn`)**：**《2025年新建设法》(Law No. 135/2025/QH15，第 86.2 条预定损害赔偿 LD 制度)**、《第 210/2026/ND-CP 号建设合同法令》第 146 条不可抗力与延误免责、《PPP法》(Law No. 64/2020)；
* **马来西亚 (`asean_my`)**：2012 年《建筑业支付与裁决法》(CIPAA 2012) 第 35 条（背靠背付款一律法定绝对无效）及第 13 条法定快速裁决、《建筑工业发展局法》(Act 520 CIDB)；
* **新加坡 (`asean_sg`)**：2004 年《建筑与施工行业快速支付法》(SOP Act 2004) 第 9 条反背靠背支付、最高法院 *BS Mount Sophia / JBE Properties*（以显失公平 Unconscionability 独立标准止付独立保函）；
* **泰国 (`asean_th`)**：《民商法典》(CCC) 承揽编第 596 条违约金酌减、《外商经营法》(FBA 1999) 附件三外资准入限制、BOI 投资促进优惠政策与 PPP 法案；
* **菲律宾 (`asean_ph`)**：**《菲律宾 PPP 法典》(RA 11966，已明文废止旧 BOT 法 RA 7718)** 特许权终止公允补偿机制、最高法院 *PCAB v. Manila Water* (G.R. No. 217590) 废除常规承包商牌照外资股比限制、《承包商执照法》(RA 4566)。

#### 2. FIDIC 国际工程标准合同双层入库与跨版本降级检索
* **多版本正本覆盖**：包含 FIDIC 银皮书 (Silver Book 1999/2017)、黄皮书 (Yellow Book 1999)、红皮书 (Red Book 1999)；
* **Tier 1 核心争议条款**：Clause 8.4/8.5 工期顺延 (EOT)、Clause 20.1/20.2 28天索赔失权通知时效、Clause 4.2 履约担保索兑限制、Clause 14.8 延误付款利息、Clause 17.3 业主风险；
* **Tier 2 基准参考条款**：Clause 1.5 解释次序、Clause 13.7 法律变更调整等；
* **智能降级机制**：若检索特定版本条款未命中，系统自动按同条款号执行跨版本等效降级召回，彻底消除检索互斥。

#### 3. 涉外国资监管与双边保护条约底座
* **双边投资保护协定 (BIT)**：《中国-东盟全面经济合作框架协议投资协议》第 6 条（公平公正待遇 FET 与间接征收补偿标准）；
* **国务院国资委 35 号令**：《中央企业境外投资监督管理办法》重大投资负面清单、合规审查与境外资产穿透监管要求；
* **中华人民共和国《数据安全法》第 36 条**：非经我国主管机关批准，不得向外国司法或者执法机构提供存储于境内的法律与工程技术数据；
* **中国出口信用保险公司 (Sinosure)**：海外投资保险与特险【30 日出险报损时效审查算子与代位求偿保全指引】。

#### 4. 纯净底层数据库规格
* **双 SQLite 存储**：不可变快照库 `law.sqlite`（收录 31 条东盟成文法规/条约、7 篇金标准裁判文书、52 个切块，历史欧美成文法完全清零）；可变运行库 `state.sqlite`（收录 C101~C104 央企实战示范案，涵盖印尼 TKDN、越南投前合规、马来 CIPAA 背靠背、新加坡保函与工期）；
* **东盟 6 国 Local Counsel 专家库**：收录印尼 BANI、新加坡 SIAC、大马 AIAC、越南 VIAC、泰国 TAI、菲律宾 CIAC 官方注册大律师与 DAAB 专家；
* **双轨检索持久化**：`bm25.pkl` 词法倒排索引 + `faiss.index` GPU 加速密集向量索引。

#### 场景 A：境外投资准入与投前合规审查 (`pre_investment`)
* **准入与架构审查**：自动化核验外资准入负面清单、原住民习惯法土地 (Hak Ulayat) 权属、国资委 35 号令事前论证与发改委 11 号令备案；

* **投前报告导出**：一键导出符合发改委境外投资备案与国资委合规要求的《东盟国家投资准入与合规审查专家意见书 (DOCX)》。

#### 场景 B：建设工程合同强行法红线扫描工作台 (`CONTRACT_REDLINE_AUDIT`)

* **五大强行法扫描规则**：
  1. 印尼 SEMA 3/2023：纯英文单语种合同行政合规风险；
  2. 马来 CIPAA 35 / 新加坡 SOPA 9：分包背靠背付款 (Pay-when-paid) 条款法定绝对无效；
  3. 新加坡 BS Mount Sophia 先例：见索即付保函排除“显失公平 (Unconscionability)”止付救济红线；

### 五、 系统部署与操作指引

#### 1. 运行环境准备
* **操作系统**：Windows 10/11 (x64) 或 Linux (Ubuntu 20.04+)
* **Python 环境**：Python 3.10.x（建议创建独立虚拟环境）
* **Node.js 环境**：Node.js v18.0+ / npm 9.0+
* **GPU 算力（可选）**：NVIDIA GPU（支持 CUDA 加速，用于本地 BGE-M3 向量化；无 GPU 自动平滑回退至 CPU）

#### 2. 服务端与前端启动步骤

**步骤一：启动 Python FastAPI 后端服务**
```powershell
# 1. 激活虚拟环境（若有）
.\v\Scripts\Activate.ps1

# 2. 设置 DashScope API Key
$env:OPENAI_API_KEY="your-api-key-here"

# 3. 启动 FastAPI 核心后端服务
uvicorn lawagent.api.main:app --host 127.0.0.1 --port 8000 --reload
```
- 后端 Swagger 接口文档：`http://127.0.0.1:8000/docs`
- 健康探针接口：`http://127.0.0.1:8000/api/health`

**步骤二：启动前端交互控制台**
另起一个终端窗口：
```powershell
cd FrontEnd
npm install      # 初次运行安装依赖
npm run dev
```
- 访问地址：`http://localhost:3000`
- 前端请求通过 Vite 代理自动转发至 `http://127.0.0.1:8000/api`。

**步骤三：自动化测试与构建校验**
```powershell
# 运行后端全量 35 项测试套件
python -m pytest tests/ -v

# 运行前端生产编译构建检查
npm --prefix FrontEnd run build
```

### 六、 下一步改进与优化方向 (Next-Step Roadmap)

经过对当前系统业务落地深度、高并发响应、多语种支持及央国企安全出海现实痛点的深入评估，确立以下五个演进优化方向：

#### 1. 多模态 EPC 复杂合同与工程证据解析 (Multimodal Ingestion & OCR)
集成版面分析（Layout-Parser）与高精度 OCR 管道，支持数百页扫描版 PDF/Word 格式 EPC 主合同、专用条件 (PC)、会议纪要与变更令 (Variation Order) 直接上传解析，自动提取时效条款与工期节点。

#### 2. 东盟涉外仲裁与工程索赔判例库纵深扩充
深度入库新加坡国际仲裁中心 (SIAC)、印尼雅加达仲裁院 (BANI)、亚洲国际仲裁中心 (AIAC) 涉及保函止付、不可抗力、工程变更的裁决案例要旨，扩充判例文书图谱关联边（`PRECEDENT_FOLLOWS`, `OVERRULES`）。

#### 3. 工程多方博弈决策树与量化和解窗口期推演 (Game-Theoretic Settlement Radar)
建立中资总包、东道国业主、属地分包商及项目融资行 (Lender) 四方博弈模型，基于决策树推演在各节点（保函索兑前、CIPAA 裁决前、SIAC 立案后）的利益敞口，测算最优和解区间（Settlement Sweet-Spot）。

#### 4. 端侧/私有化 LLM 部署与物理隔离适配 (On-Premises & Air-Gapped Serving)
针对涉密基建工程严格符合《数据安全法》第 36 条要求，适配 Ollama / vLLM 离线推理引擎，支持开源模型在企业私有算力服务器上一键部署并实现完全物理隔离。

#### 5. 东盟本土语种法律意见书与矢量 PDF 报告导出
引入矢量排版引擎，扩展生成印尼语（Bahasa Indonesia）、越南语（Tiếng Việt）或泰语法律意见摘要与合规示范条款，满足直接向东道国部委与法庭呈递规范文书的需求。
