### 一、 系统定位与核心价值

在中国基建央企、国企“走出去”参与“一带一路”及东盟互联互通工程的实务中，出海企业与法务团队常面临多重严峻挑战：东道国强行法与本地化行政规章庞杂、语言壁垒森严、合同背靠背陷阱频现、见索即付保函恶意索兑风险高发；同时，通用大模型存在严重的“法条幻觉”、生硬的“AI 模板味”以及脱离工程实操的“单一伪量化胜诉率（如机械展示 88% 胜诉率）”。

**OverseasLawAssist（域外法查明与深度研判智能工作台）** 是专为中国涉外法官、涉外仲裁员、基建央国企涉外法务合规官及跨境争议解决律师研发的现代化桌面级专业平台。系统已彻底剥离宽泛的历史欧美商事法域，全面聚焦于**东盟 6 国（印度尼西亚、越南、马来西亚、新加坡、泰国、菲律宾）建设工程（EPC/PPP/特许经营/跨境并购/联营体）法律风险防范、合同强行法红线扫描、履约争议推演、全周期合规自测与 Local Counsel 专家协同**。

系统严格贯彻**司法中立防线（V8 Anti-Predictive Guardrail）**，彻底摈弃伪量化胜诉率，创新采用**假定条件推演矩阵（Condition Precedent If-Then Matrix）**与**三维定性结论遥测**，依托确定性算子、三层刚性安全哨兵与真实 SQLite 持久化，为出海基建提供端到端真实闭环的决策支持。

### 二、 支持法域与权威数据底座 (Pure ASEAN & FIDIC Architecture)

#### 1. 东盟 6 国 2026 现行有效法源与司法部“法通网”三语对齐
* **印度尼西亚 (`asean_id`)**：印尼最高法院《2023年第3号通告》(SEMA No. 3/2023，反制纯英文合同机械无效抗辩)、《建筑服务法》(UU No. 2/2017) 第 57 条、《能矿部 11/2024 号条例》(MEMR Reg 11/2024 电力设备 TKDN 本地化率豁免申请机制)、印尼《民法典》(KUHPerdata) 第 1338 条善意履约原则；
* **越南 (`asean_vn`)**：**《2025年新建设法》(Law No. 135/2025/QH15，第 86.2 条预定损害赔偿 LD 制度)**、《第 210/2026/ND-CP 号建设合同法令》第 146 条不可抗力与延误免责、《PPP法》(Law No. 64/2020)；
* **马来西亚 (`asean_my`)**：2012 年《建筑业支付与裁决法》(CIPAA 2012) 第 35 条（背靠背付款一律法定绝对无效）及第 13 条法定快速裁决、《建筑工业发展局法》(Act 520 CIDB)；
* **新加坡 (`asean_sg`)**：2004 年《建筑与施工行业快速支付法》(SOP Act 2004) 第 9 条反背靠背支付、最高法院 *BS Mount Sophia / JBE Properties*（以显失公平 Unconscionability 独立标准止付独立保函）；
* **泰国 (`asean_th`)**：《民商法典》(CCC) 承揽编第 596 条违约金酌减、《外商经营法》(FBA 1999) 附件三外资准入限制、BOI 投资促进优惠政策与 PPP 法案；
* **菲律宾 (`asean_ph`)**：**《菲律宾 PPP 法典》(RA 11966，已明文废止旧 BOT 法 RA 7718)** 特许权终止公允补偿机制、最高法院 *PCAB v. Manila Water* (G.R. No. 217590) 废除常规承包商牌照外资股比限制、《承包商执照法》(RA 4566)。

#### 2. FIDIC 国际工程标准合同双层入库与跨版本降级检索
* **多版本正本覆盖**：包含 FIDIC 银皮书 (Silver Book 1999/2017)、黄皮书 (Yellow Book 1999)、红皮书 (Red Book 1999)；
* **Tier 1 核心争议条款**：Clause 8.4/8.5 工期顺延 (EOT)、Clause 20.1/20.2 28天索赔失权通知时效、Clause 4.2 履约担保索兑限制、Clause 14.8 延误付款利息、Clause 17.3 业主风险；
* **Tier 2 基准参考条款**：Clause 1.5 解释次序、Clause 13.7 法律变更调整等；
* **智能降级机制**：若检索特定版本条款未命中，系统自动按同条款号执行跨版本等效降级召回，消除检索互斥。

#### 3. 涉外国资监管与双边保护条约底座
* **双边投资保护协定 (BIT)**：《中国-东盟全面经济合作框架协议投资协议》第 6 条（公平公正待遇 FET 与间接征收补偿标准）；
* **国务院国资委 35 号令**：《中央企业境外投资监督管理办法》重大投资负面清单、合规审查与境外资产穿透监管要求；
* **中华人民共和国《数据安全法》第 36 条**：非经我国主管机关批准，不得向外国司法或者执法机构提供存储于境内的法律与工程技术数据；
* **中国出口信用保险公司 (Sinosure)**：海外投资保险与特险【30 日出险报损时效审查算子与代位求偿保全指引】。

#### 4. 纯净底层数据库规格
* **不可变快照库 `law.sqlite`**：收录 31 条东盟成文法规/条约、7 篇金标准裁判文书、52 个语义分块（历史欧美成文法完全清零）；

* **东盟 6 国 Local Counsel 专家库**：收录印尼 BANI、新加坡 SIAC、大马 AIAC、越南 VIAC、泰国 TAI、菲律宾 CIAC 官方注册大律师与 DAAB 专家；
* **双轨检索持久化**：`bm25.pkl` 词法倒排索引 + `faiss.index` GPU 加速密集向量索引。

### 四、 核心功能与工作台详述

#### 1. 首屏极速双轨制 (`HomeLandingView.tsx`)
* **轨道 A（占宽 60% · 30 秒合同强行法红线极速扫描）**：
  * 支持输入英文或中英双语合同条款，提供印尼 SEMA 3/2023、大马 CIPAA 35、新加坡保函止付等典型高危条款一键填入；
  * 点击即刻输出三联式诊断卡：**① 强行法效力判定**（如：违反 CIPAA 第 35 条 · 法定绝对无效） $\to$ **② 诉讼/仲裁后果预警** $\to$ **③ 平衡修改示范条款（Redline 一键复制）**；
  * 底部提供 **【以此条款一键升级为深度专案】**，自动携带参数打开建案弹窗。
* **轨道 B（占宽 40% · 深度专案查明与标杆示范卷）**：
  * 顶部常驻 **【+ 粘贴邮件/索赔函极速建案】** 入口；
  * 下方展示 C101（印尼火电 TKDN 与工期）、C102（越南海风并购准入）、C103（大马分包背靠背）、C104（新加坡地铁保函止付）标杆案卷卡片，点击秒切进入研判舱。

#### 2. 零门槛智能案情抽提舱 (`CaseEntryModal.tsx`)
* **AI 智能要素抽提舱 (Smart Ingestion Box)**：
  * 粘贴一段原始英文往来邮件、业主索赔通知函（Claim Notice）或招标文件，点击 **【一键智能抽提建案要素】**；
  * 调用后端 `POST /api/cases/extract-intake`，2 秒内自动提炼项目名称、东道国、准据法、生命周期阶段（`pre_investment` / `execution_dispute`）、工程业态、事实与诉求摘要，并精准抽取天数、TKDN 比例等工程数值参数填入表单；
* **跨组件带参预填孵化**：
  * 从【合规中心未达标项】、【六国比选矩阵】或【合同红线扫描仪】跳转时，自动预填上下文并高亮来源。

#### 3. 专案深度研判舱——生命周期双模自适应「四切面」矩阵 (`CaseAnalysisView.tsx`)
支持键盘快捷键 `1`、`2`、`3`、`4` 秒切，视图随生命周期模式（投前准入 `pre_investment` vs 履约争议 `execution_dispute`）自动切换专业话术与评估维度：

* **切面 1：决策全景看板 (Executive Verdict & If-Then Matrix)**
  * **三维定性结论遥测带**：严守 V8 防线，废除虚假单一胜诉率。争议模式展示：`[实体法理支持度：强支持 (82%-90%)]`、`[程序抗辩敞口：可控中度威胁]`、`[反制阻断预期：高确定性阻断]`；投前模式展示外资准入可行性、属地强行法敞口与国资委 35 号令备案就绪度；
  * **假定条件推演矩阵 (If-Then Condition Matrix)**：三阶泳道（乐观假定 / 基准稳健 / 底线突破），清晰揭示自由心证分水岭；
  * **准据法脱钩穿透警示卡**：当东道国与合同准据法不一致时，自动呈现琥珀色 `Lex Loci Override` 穿透警示。
* **切面 2：争点拆解 & 要件四态涵摄 (Issues & Statutory Elements)**
  * 左栏争议焦点/准入支柱列表，右栏对应要件四态胶囊比对卡（`✓ 已满足`、`◐ 部分满足`、`✕ 缺失`、`? 存疑`）；
  * 每张卡片分为：`[法定要件与法条徽章]` $\to$ `[在卷事实涵摄判定]` $\to$ `[证据缺口与补强入口]`；点击法条直接呼出右侧副驾坞精读。
* **切面 3：工程沙盘 & 攻防工坊 (What-If Sandbox & Battlecards)**
  * **左舱精密沙盘**：在滑轨上物理绘制法定红线刻度锚点（`28d FIDIC 失权线`、`40% TKDN 红线`、`30d 中信保报损线`）；
  * **右舱实时联动**：滑块越过红线瞬间触发高亮呼吸动效，实时联动刷新后端返回的 **《中英双语商务谈判反驳话术卡》** 与 **《7 日内紧急发函与取证清单》**；内置竞态版本锁，保证快速拖拽丝滑不跳字。
* **切面 4：法源穿透图谱 & 意见书交付 (Citation Graph & Quality Gate)**
  * 顶部展示 Critic V1~V12 司法门禁遥测条；
  * 左下展示 3-Layer 交互式法源拓扑图谱（`InteractiveCitationGraph.tsx`）；
  * 右下提供实时公文级双语意见书预览器，支持一键导出最高法标准 Word (.docx) 报告与合规手册。

#### 4. 轻量独立工具箱与案卷真实挂载闭环 (Toolbox & Artifact Loop)
* **合同红线 & 外律意见书核验仪 (`MaterialVerificationView.tsx`)**：
  * 支持涉外合同条款强行法扫描与外律意见书引证防伪验真；
  * 新增 **`[+ 挂载体检记录至当前案卷]`**（调用 `POST /api/cases/{id}/attach-artifact` 真实存入案卷运行库）与 **`[以此条款新建深度专案]`**。
* **东盟六国现行法典与判例搜索引擎 (`NormSearchEngineView.tsx`)**：
  * 修复“未搜索即展示 32 条结果”痛点：未输入时处于**《权威基准法源导航目录》**模式，按法域分类展示现行有效法典；
  * 输入关键词后平滑切换为精准检索流；每张卡片前置【权威法源认证 · 现行有效】金牌背书，支持 **`[+ 引用至当前案卷]`**。
* **东盟 Local Counsel 与 DAAB 专家协同枢纽 (`ExpertConsultsView.tsx`)**：
  * 预置 6 国资深大律师与仲裁员档案，在线执行利益冲突 (COI) 排查，排查会商记录一键挂载至案卷。

#### 5. 东盟合规与排雷知识底座 (`ComplianceCenterView.tsx`)
* **五阶段 × 三道防线合规体检表**：
  * 打分状态与判定通过 `localStorage` 自动持久化，支持一键重置；
  * 发现瑕疵或未达标项时，右侧浮现 **`[针对此缺口发起专案推演 ➔]`**，携带全部上下文参数一键建案。
* **6×12 风险排雷矩阵与 5D 典型案例卡**：
  * 严格遵守 3 行文本熔断法则，点击圆点或案例卡片直接滑出右侧统一副驾坞（模态 3：属地排雷速查）展开精读。

#### 6. 单实例多模态右侧统一副驾坞 (`UnifiedRightDock.tsx`)
* 停靠主视口右侧（宽度 `440px`，快捷键 `Cmd/Ctrl + B`），通过顶部滑动 Segmented Control 切换三大内联模式：
  1. **`[法源双语精读 (Law Reader)]`**：权威背书信息、中外双语对照文本、法理释义与案卷引用入口；
  2. **`[案卷 AI 副驾 & 流水线 (Case Copilot)]`**：S1~S9 推理节点耗时轨迹、多轮上下文追问对话、高频追问建议胶囊；
  3. **`[属地排雷速查 (Country Playbook)]`**：自动锁定当前国别，提供 12 大风险域 Do's & Don'ts 对照与 5D 案例全文。

#### 7. 全局聚焦命令舱 (`CommandPaletteModal.tsx`)
* 遵循 macOS Spotlight / Linear 规范，全局按下 **`Cmd/Ctrl + K`** 原地唤出：
  * 支持输入拼音/中英文秒级模糊匹配案卷、快速检索法典条文、一键切换投前合规/履约争议生命周期阶段、快速呼出独立工具。

### 五、 现代工业级视觉规范 (Apple HIG × Fluent 2 VIA)

系统全面落实《重构方案.md》模块一的视觉信息架构规范：
1. **彻底绝迹 AI 模板味（Denylist 执行到位）**：
   * 移除主界面所有普通卡片上堆砌的 `Sparkles`（星星）、`Bot`（机器人）图标，代以 `Scale`、`ShieldAlert`、`FileCheck2` 等严谨工程法典图标；
   * 摒弃大面积高饱和度红黄浅色涂抹底框与彩虹渐变，风险等级严格采用 **6px 光学呼吸圆点（`.glow-dot-*`）+ 紧凑胶囊徽章（Pill Badge）** 表达。
2. **3 行文本熔断法则 (3-Line Text Circuit Breaker)**：
   * 主画布任何卡片禁止渲染超过 3 行的连续自然段文字，全部结构化为视觉原语：`[状态胶囊]` + `[1句话核心判定]` + `[法条锚点]` + `[副驾坞展开入口]`。
3. **光学材质体系**：
   * **Mica 矿物微光画布（`.mica-canvas`）**：冷调石英灰底色叠加极低饱和度环境冷光；
   * **Acrylic 亚克力卡片（`.acrylic-card`）**：`backdrop-filter: blur(20px)`，叠加 `1px` 镜面内高光；
   * **深空钛金属按钮（`.btn-space-titanium`）**：深邃曜石钛黑渐变（`#1E293B` $\to$ `#0F172A`）；
   * **数字等宽遥测（`tabular-nums`）**：所有天数、百分比、金额数字采用等宽字体，拖动滑块绝对零抖动。

### 六、 系统部署与操作指引

#### 1. 运行环境要求
* **操作系统**：Windows 10/11 (x64) 或 Linux (Ubuntu 20.04+)
* **Python 环境**：Python 3.10.x
* **Node.js 环境**：Node.js v18.0+ / npm 9.0+
* **GPU 算力（可选）**：NVIDIA GPU（支持 CUDA 加速，用于本地 BGE-M3 向量化；无 GPU 自动平滑回退至 CPU）

#### 2. 服务端与前端启动步骤

**步骤一：启动 Python FastAPI 后端服务**
```powershell
# 1. 激活虚拟环境（若有）
.\v\Scripts\Activate.ps1

# 2. 设置 DashScope API Key（可选，无 Key 时本地确定性规则引擎 100% 自动兜底）
$env:OPENAI_API_KEY="your-api-key-here"

# 3. 启动 FastAPI 核心后端服务
uvicorn lawagent.api.main:app --host 127.0.0.1 --port 8000 --reload
```
- 后端 Swagger 接口文档：`http://127.0.0.1:8000/docs`
- 健康探针接口：`http://127.0.0.1:8000/api/health`

**步骤二：启动前端交互控制台**
另起一个终端窗口：
```powershell
cd FrontEnd
npm install      # 初次运行安装依赖
npm run dev
```
- 前端访问地址：`http://localhost:3000`
- 请求通过 Vite 代理自动转发至 `http://127.0.0.1:8000/api`。

**步骤三：自动化回归测试与生产构建校验**
```powershell
# 运行后端全量 37 项单元与集成测试（涵盖新路由、数据挂载与算子）
$env:PYTHONPATH="."
python -m pytest tests/ -v

# 运行前端生产编译构建检查（0 Error, 0 Warning）
npm --prefix FrontEnd run build
```
